## 1. Unity 版本选型（关键决策点）

**结论：采用方案 A —— Unity 6.3 LTS（6000.3.x），已确认。**

| 方案 | 版本 | 说明 | 决策 |
|---|---|---|---|
| A（已采用） | **Unity 6.3 LTS（6000.3.x）** | 当前可用的长期支持版；URP 17 成熟、移动端优化好、支持期到 2027-12（企业/行业可延至 2028-12） | ✅ 采用 |
| B（已否决） | ~~Unity 2022.3 LTS~~ | 上一代 LTS，**官方支持已于 2025-05-07 结束（EOL）** | ❌ 否决 |
| C（不推荐） | Unity 6.4 / 6.5 / 6.6 | 属于"更新版本（Update Release）"，只支持到下一个版本发布，不适合作为发布基线 | ⚠️ 观察 |

**说明：**
- 本项目为全新 3D 项目，无历史包袱，直接用 Unity 6 LTS 系列。
- **版本锁定策略：全队统一锁定 `6000.3.x` 某一具体 patch，写进本文档；后续只在该 LTS 线内升级 patch（且需跑通真机构建），不跨大版本、不升 Update Release。**
- **本项目锁定版本：`6000.3.24f1`**（2026-09-15 已安装于 `/Applications/Unity/Hub/Editor/6000.3.24f1`，国际版，无 `c1` 后缀）。

### 1.1 为何否决方案 B（Unity 2022.3 LTS）

| 问题 | 说明 |
|---|---|
| **已停止支持** | 2022.3 LTS 官方支持 2025-05-07 结束，最后一版 2022.3.62f3；无安全修复、无新平台 SDK 适配 |
| **Google Play 合规硬伤** | Google Play 每年强制提升 target API；停止更新的引擎无法跟进新政策，后续更新/上架有被拒风险 |
| **插件兼容性优势在本项目不成立** | B 的"生态插件最稳"只对依赖老旧插件的老项目有价值；本项目只依赖官方包（Addressables / Localization / Input System）+ DOTween / UniTask，无历史包袱 |
| **升级成本后置且集中** | 2022.3 → Unity 6 需逐级迁移，涉及：URP 14 → 17（Renderer Feature / `ScriptableRenderPass` API 变更、自定义 Shader 与后处理易坏）、JDK/NDK/Gradle/AGP 换版、全量资源重导（Git/LFS 大 diff）、Addressables/Localization 等包 breaking change、广告与支付 SDK 换版、自研关卡编辑器适配编辑器 API。预计 3~10 人日集中处理 + 回归测试，且大概率发生在内容量产或上架前夕 |
| **与长期运营目标冲突** | 需求文档 §3.2 要求"新章节以扩展包下发、无需发版"，需引擎具备长期可维护性 |

### 1.2 降低未来升级成本的开发约定（选 A 也需遵守）

1. **核心逻辑与引擎解耦**：投影判定、关卡数据结构、存档序列化等纯 C# 实现，不依赖 URP / 渲染 API，便于后续跨版本、跨平台（iOS / WebGL）复用。
2. **少写自定义 RenderPass**：异次元视觉优先用 URP 原生后处理 + Shader Graph，避免 RenderGraph 化带来的迁移成本。
3. **不使用 preview / beta 包**：Addressables、Localization、Input System 一律使用 6000.3 已验证的稳定版本，并在文档中记录版本号。
4. **第三方 SDK 谨慎引入**：广告 / 内购 SDK 与引擎版本强绑定，引入前确认支持 6000.3，并记录版本对应关系。

**国际版 vs 中国版：**
- 国际版（Unity 国际官网下载）：面向海外发布首选，许可证走 Unity 官网账号，无国内定制服务。
  - 中国版：由团结引擎/Unity 中国运营，含国内 SDK 生态，但部分行为与国际版有差异。
  - **海外发布 → 必须使用国际版 Unity Hub + 国际版 Unity Editor**，避免后续导出与合规差异。
- 许可证：个人版（Personal）免费，年收入/融资低于 Unity 门槛（当前 20 万美元）即可免费商用，启动画面可关闭。

   - 本机状态：Git `2.28.0` 已有；**Git LFS `3.8.0` 已安装**（见 §5 执行记录）。
4. 代码编辑器：VS Code（装 Unity 扩展）或 Rider

### 2.2 项目模板与设置
- 模板：**3D (URP)**（Built-in 已不推荐用于新项目）
- Unity 项目初始设置：
  - Player Settings → Company Name / Product Name / 包名（如 `com.<你的工作室>.shadowcube`，一经上架不可改）
  - Scripting Backend：**IL2CPP**（Google Play 强制 64 位）
  - Target Architectures：**ARM64**（可同时勾 ARMv7）
  - Minimum API Level：Android 8.0 (API 26)
  - Target API Level：**Automatic (Highest Installed)**——Google Play 每年要求新版 target API（2026 年需 API 36），保持自动跟随
  - Color Space：Linear（URP 默认）
  - Graphics API：Vulkan 优先 + GLES3 兜底
- 建议关闭 Auto Graphics API 中的 Vulkan 兼容问题机型黑名单（后期按测试情况调整）

### 2.3.1 音频环境
- 使用 Unity 原生 Audio（**不引入第三方音频中间件**），配 **AudioMixer** 分总线：`Master / BGM / SFX`。
- 资源约定（写进导入设置，前期就定好，避免后面对齐返工）：
  - 短音效（按钮/生成/消除/镜头）：**WAV 或 ADPCM**，Load Type = Decompress on Load，保证零延迟
  - BGM：**OGG/Vorbis**，Load Type = **Streaming**，Compression 适度
  - 采样率 44100Hz，单声道优先（移动端省内存），BGM 可立体声
- Git LFS 需额外追踪：`*.wav *.ogg *.mp3 *.aif`（见 §2.4）。
- 前期无音频资源时，用占位音效（正弦短音）驱动 `AudioService` 开发，后期整体替换。

### 2.4 版本管理
- Git 仓库（GitHub 私有仓库，海外协作友好）
- Unity `.gitignore`（Library/ Temp/ Logs/ obj/ 等忽略）
- **Git LFS** 追踪：`*.png *.psd *.fbx *.wav *.ogg *.mp3 *.aif *.unitypackage`
- Unity 项目设置：Version Control → Visible Meta Files；Asset Serialization → Force Text（默认已如此）

### 5.4 ⚠️ 中国大陆网络的地域路由问题（已实测）

Unity 会按 **IP 所在地**把中国大陆用户路由到 Unity 中国（unity.cn / 团结引擎）体系，与"装哪个包"无关：

| 实测请求 | 结果 |
|---|---|
| `https://unity.com/download` | **302 → `https://unity.cn/releases`** |
| `https://public-cdn.cloud.unity3d.com/hub/prod/releases-darwin.json` | **307 → `public-cdn.cloud.unitychina.cn`，内容只有 `c1` 中国版版本** |
| Hub 登录 | 被导向 **`id.unity.cn`**（Unity 中国账号体系） |

**已安装 Hub 的核验结论（是国际版）**：`app.asar` 内含 `id.unity.com`（4 处）、`license.unity3d.com`（5 处）、`download.unity3d.com`（150 处）；唯一的 `unity.cn` 出现在 EULA 文本中，原文大意为"根据你的所在地，Editor 版本权利以 unity.cn/releases 为准"——即**国际版 Hub 内置的地域分流逻辑**。

**账号体系不通用**：`id.unity.com`（Unity ID，国际）与 `id.unity.cn`（Unity 中国）是两套账号，许可证也不互通。走 `id.unity.cn` 只能拿到中国版 Editor（版本号带 `c1` 后缀）或团结引擎，**不满足海外 Google Play 发布要求**。

**解决办法（任选其一）**：
- **A（推荐）**：用非中国大陆出口的网络（代理 / 海外节点，全局模式）启动 Hub，完成登录、激活、下载 Editor，之后日常使用不受影响。
- **B**：绕开 Hub，直接用国际直链下载 Editor 安装包（仍需国际网络取 changeset，且许可证激活需国际 Unity ID）：
  `https://download.unity3d.com/download_unity/<changeset>/MacEditorInstaller/Unity-6000.3.24f1.pkg`
- **C（不可取）**：改用 Unity 中国版 / 团结引擎——与需求文档 §6（海外发布、AdMob/Unity Ads 海外版位）冲突。

**判断是否已走国际渠道**：Hub → Installs → Add 列表中能看到 **`6000.3.x`（不带 `c1`）** 即为国际版；只有 `c1` 或"团结引擎"则说明仍在中国区。

## 7. 包名（Application Identifier）设定规则

- 格式：`com.<标识>.shadowcube`，**全小写、不能有连字符（`-`）、不能以数字开头**，建议只用 `a-z0-9`。
- **一经上架不可更改**（Google Play 以包名作为应用唯一 ID），所以现在必须定死。
- 标识怎么选（按推荐顺序）：
  1. **有自有域名** → 域名反写，如 `nebula.games` → `com.nebula.games.shadowcube`（或取一级 `com.nebula.shadowcube`）

## 8. 第三方库说明：UniTask / DOTween

| 库 | 是什么 | 用在哪 | 是否建议引入 |
|---|---|---|---|
| **UniTask**（Cysharp） | Unity 的 `async/await` 异步方案，替代 Coroutine 与 `Task`，**零 GC、可 await 帧/秒/动画/资源加载**，能直接 `await` 并拿到返回值 | 关卡资源加载（Addressables）、提示演示的"逐块生成"序列、场景切换、广告回调等待、存档 IO | **建议引入**（M2 起）。提示演示与资源加载用 await 写比 Coroutine 嵌套清晰得多 |
| **DOTween**（Demigiant） | 补间动画库，一行代码做位移/缩放/淡入淡出/序列动画 | 方块生成弹出、消除碎裂、星级点亮、UI 弹窗、镜头吸附回弹、投影墙高亮 | **建议引入**（M3 美术打磨阶段）。基础版免费可用 |

- 两者都是 Unity 生态事实标准、MIT/免费（DOTween 有付费 Pro，非必需）。
- 都不会造成平台限制（iOS / WebGL 均支持）。
- 若你倾向"尽量少依赖"：DOTween 价值最高（动效到处都要），UniTask 可以等到 M3 再决定。
- ✅ **已确认：两者都引入**。安装方式：
  - **UniTask**（UPM，推荐）：Package Manager → `+` → Add package from git URL →
    `https://github.com/Cysharp/UniTask.git?path=src/UniTask/Assets/Plugins/UniTask`
  - **DOTween**：Asset Store 导入（免费版）后，用 `Tools → Demigiant → DOTween Utility Panel` 初始化；或 Package Manager 加第三方 UPM 镜像源。
  - 安装后把两者的确切版本记录到本表，并在 `Packages/manifest.json` 中锁定。

## 9. 中文字体"子集化"说明

- **问题**：完整中文字体（如思源黑体、苹方）含 2~3 万字形，做成 TextMeshPro 字体资源通常 **5~15MB**，直接打包会显著撑大包体（首包目标 < 80MB）。
- **子集化**：只把**游戏里实际会用到的那几百个汉字**从字体里"切"出来，生成一张小的 SDF 字形图集（通常 **200KB~1MB**），包体立省 90%+。
- **本项目的推荐做法**：
  1. 中文用**静态子集**：把所有中文文案（UI + 关卡名 + 提示语）收集成一个字符集，用 **TMP Font Asset Creator** 生成 `Font_zh-CN` 子集（建议含常用标点 + 3500 常用字留余量，约 1~2MB）。
  2. 英文用独立字体（几百 KB）。
  3. 再配一个 **Dynamic 模式的 Fallback 字体**（可选，用系统字体或按需下载的完整字体），保证偶尔出现生僻字时不显示"豆腐块"。
- **代价**：子集外的字不会显示 → 每次新增中文文案后需重新生成子集（可写个编辑器脚本一键收集 + 生成，M4 做）。
- **替代方案**：完整字体走 Addressables **按需下载**（首次进中文界面时下载），包体小但要多一次下载与失败兜底。
